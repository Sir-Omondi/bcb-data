## What's in this release

- Full English text for Genesis 1:1–2:25
- Hebrew original text with transliteration for every verse
- Verse-level study notes (theological, historical, cultural, linguistic)
- Word headings grouping verses by theme and creation day
- Root word entries for key Hebrew roots (bara, reshit, elohim, shavat, yatsar, ezer…)
- Lexical entries with full scholarly definitions, semantic range, and translation alternatives
- Cross-references linking Genesis 1–2 to John 1, Exodus 20, Hebrews 4, Matthew 19, and 1 Corinthians 15

## How to install

1. Open **BC Bible** on your device
2. Go to **Settings → Data & Updates**
3. Tap **Check for Updates**
4. Select this release and tap **Install**

Or download `data.json` from this release and import it directly.
